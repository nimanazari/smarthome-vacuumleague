# 🔒 Organizer only · فقط برگزارکننده

این پوشه **هرگز به تیم‌ها داده نمی‌شود** و کیت‌ساز هم آن را داخل TeamKit
نمی‌گذارد. This folder never ships to the teams.

## `champions/` — کدهای کامل مرجع
راه‌حل کامل هر رده، برای **تستِ خودت**:

| فایل | رده | چطور تست کنم |
|---|---|---|
| `champ_fs.py`  | FS  | در بازی، کد را در ادیتور تیم ۲ بگذار و برنامه‌ی تیم شرکت‌کننده را مقابلش بگذار |
| `champ_u14.py` | U14 | همین‌طور — هر ترفندش اندازه‌گیری شده |
| `champ_u19.py` | U19 | باتری + سطل خاک + سرقت کاشی |

در نسخه‌ی خودت (پروژه‌ی اصلی) این سه، در منوی «ربات‌های آماده» هم هستند؛
در TeamKit از منو و از پوشه‌ی bots حذف می‌شوند تا بچه‌ها راه‌حل را
کپی نکنند — بقیه‌ی ربات‌های آموزشی (wallfollow، easymoves، goto…)
برای تیم‌ها می‌ماند.
