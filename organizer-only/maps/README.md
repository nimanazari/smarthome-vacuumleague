# 🏁 نقشه‌های مسابقه · The competition maps

پنج پوشه، پنج نقشه: `map1/` تا `map5/` — هر کدام یک `map.json`.
این پوشه فقط در کیت برگزارکننده است (AdminKit) و **هرگز در TeamKit یا
ریپوی عمومی تیم‌ها نیست**؛ بچه‌ها نقشه‌ها را در روز مسابقه می‌بینند —
یا اگر بخواهی، از سایت (بخش پایین).

Five folders, five maps, one `map.json` each. Organiser kit only — never
in the TeamKit or the public teams repo.

## چطور کار می‌کند · how it works

1. `serve.bat` را بزن. چون `tools/mapserver.py` کنارش هست، همان بازی با یک
   قابلیت اضافه بالا می‌آید: خواندن و **ذخیره‌ی** این پنج پوشه.
2. در بازی، منوی نقشه پنج گزینه‌ی 🏁 «مپ ۱ تا ۵» دارد (فقط آن‌هایی که
   روشن‌اند). کنارش کلید **🚪 درها** است: «طبق نقشه»، «همه باز» (درِ
   هل‌دادنی حذف می‌شود)، «همه بسته».
3. در مپ‌ساز (دکمه‌ی ✏️ کنار نقشه، یا `leagues/vacuum/mapmaker.html`)
   بخش **«🏁 نقشه‌های مسابقه»** هست: هر مپ را باز کن، ویرایش کن، «ذخیره در
   مپ N» (یا Ctrl+S) — همان لحظه در `mapN/map.json` نوشته می‌شود و نسخه‌ی
   قبلی به `map.json.bak` می‌رود. دکمه‌ی ● روشن / ○ خاموش هر مپ را از لیست
   بازی بیرون می‌برد یا برمی‌گرداند (یک فایل خالی به اسم `OFF` در پوشه).
4. تیک «🚪 درها کامل باز باشن» در مپ‌ساز، در خودِ نقشه ثبت می‌شود
   (`doorsOpen: true`) — مپ ۱ این‌طور ساخته شده.
5. بعد از هر ویرایش: `node tools/validate-map.js map1` (یا map2 … map5).

## روی سایت · on the site

همین پنج اسلات روی smarthomeleague.ir هم هست: `/admin` → تب **Maps** →
روشن/خاموش، **edit** (مپ‌ساز روی سایت، فقط ادمین)، **upload map.json**
(همین فایل‌ها) و **download**. بازیِ `/game/` سایت همان 🏁ها را نشان
می‌دهد. نسخه‌ی اولیه‌ی هر پنج مپ با `competition-maps.seed.json` همراه
سایت می‌رود؛ هر ذخیره‌ی ادمین در `data/competition-maps.json` سرور
می‌ماند و با دیپلوی بعدی پاک نمی‌شود.

The same five slots live on the site: `/admin` → **Maps** tab (on/off,
edit in the admin-only Map Maker, upload / download `map.json`).
